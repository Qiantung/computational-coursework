# Single-cycle RISC-V coursework

保留课程设计中的 Verilog 模块、原测试台与指令输入文件。作者确认这些代码由本人编写/修改。此处展示的是**单周期**教学实现；原材料提出的五级流水线与乱序执行属于设想，未实现。

在 Vivado 新建仿真工程，加入本目录模块与 `testbench/`，选择对应测试台运行。当前 `instruction_memory.v` 在源码内初始化指令 ROM；`code.txt` 作为历史输入材料保留，替换它并不会自动更新 ROM。各模块接口以源码为准。

本次整理只检查文件和模块结构，未安装 Vivado/Verilog 仿真器，未复验全部指令或原报告中的正确性结论。需补充完整指令覆盖、复位与访存边界测试后再作为处理器正确性依据。未上传 Vivado 构建缓存、IP 产物或工具自带 glbl.v。
